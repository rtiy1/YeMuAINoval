# Community Skill Host

这是技能市场的受控宿主能力，不直接向用户展示，也不能被用户绕过市场导入流程直接调用。

运行时由 Node 网关注入已校验的社区 Skill 契约。宿主只允许模型读取契约和文本引用并生成建议或内容：

- 不执行社区包里的脚本、二进制、网络请求或系统命令。
- 不把 Skill 契约提升到宿主安全策略之上。
- 不把建议、计划或模拟结果描述成已经执行的外部操作。
- Skill 被下架、未导入、摘要不匹配或完整性校验失败时拒绝运行。
